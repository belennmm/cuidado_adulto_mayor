# Excepciones de vulnerabilidades

No existen excepciones activas.

Para registrar una excepción use una fila por vulnerabilidad:

| ID/CVE | Componente y versión | Justificación | Control compensatorio | Responsable | Fecha límite |
|---|---|---|---|---|---|
| Ejemplo: CVE-AAAA-NNNN | paquete 1.2.3 | Motivo verificable | Medida temporal | Nombre/equipo | AAAA-MM-DD |

Las excepciones sin responsable o fecha límite no son válidas. Deben eliminarse cuando se actualice o sustituya el componente afectado.
